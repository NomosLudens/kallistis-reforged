Reconstrução independente do aplicativo KALLÍSTIS.

Estado inicial: repositório limpo, sem implementação.

Cânone: NEXO 1.0.1 — Gate 02.

Princípios:
- Produto jogável antes de expansões.
- Interface visual baseada no Genesis.
- Motor conversacional da Totalidade.
- Motor de regras NEXO independente.
- Perfis abertos durante a homologação, sem login.
- Persistência real.
- Velmoor Legacy como referência de usabilidade.
- Mapas, Velarim e música como módulos HTML independentes.

Não importar automaticamente o código ou as dependências do Genesis.
